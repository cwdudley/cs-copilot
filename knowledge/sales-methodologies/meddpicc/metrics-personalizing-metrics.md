# Personalizing Metrics per Stakeholder

## Core argument

If your metrics sound identical for every stakeholder in a deal, that is a
warning sign. The same organizational pain shows up differently for each
person, and company-level metrics do not create personal urgency.

**People drive decisions, not companies.** Stakeholders prioritize what affects
their own day-to-day responsibilities. A deal that solves a real company problem
can still sit low on every individual's priority list.

## Scale of the problem

MEDDICC cites roughly seven decision-makers in a typical mid-market evaluation
and about double that in enterprise. Generic metrics across that many people
leave value unclaimed.

## What to do

- Translate the shared pain into each stakeholder's terms and measures.
- Show each person the specific, quantified change for their area.
- Use personalized metrics to build a wider network of invested stakeholders —
  which increases deal velocity and reduces single-champion dependency.

## Coaching questions this supports

- For each stakeholder, what number would they personally care about moving?
- Which stakeholders have only heard the company-level business case?
